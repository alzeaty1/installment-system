# خطة: نسخ احتياطي خارجي — Google Drive + تيليجرام

> **For Hermes:** تنفيذ مباشر بعد موافقة المستخدم.

**Goal:** النسخة اليومية التلقائية للداتابيز تتوصل لبرة الجهاز بطريقتين:
1. **تيليجرام**: البوت الموجود أصلًا يبعت ملف النسخة (sqlite3 ~0.5MB) لشاتك كل يوم.
2. **Google Drive**: رفع يدوي/نصف تلقائي — زر في صفحة الإعدادات يفتح Drive، أو مجلد Drive Desktop لو مثبت.

**القرارات المعتمدة من المستخدم:** تيليجرام + جوجل درايف. البوت موجود عند Hermes بالفعل (TELEGRAM_BOT_TOKEN + TELEGRAM_HOME_CHANNEL في hermes .env) — هنستخدم نفس التوكن في Django.

## Task 1 — إرسال النسخة اليومية على تيليجرام (الأهم)

**Files:**
- Modify: `installments/core/middleware.py` (`_maybe_backup`) — بعد `create_backup()` نجاح، ابعت الملف
- Create: `installments/core/telegram_notify.py` — دالة صغيرة `send_backup_to_telegram(path)` تستخدم Bot API مباشر (requests multipart upload)
- Modify: `installments/.env` (مش مرفوع على git): `TELEGRAM_BOT_TOKEN=...`, `TELEGRAM_BACKUP_CHAT_ID=<chat_id بتاعك>`
- Modify: `core/views.py` settings page → مؤشر حالة آخر إرسال

**Logic:**

```python
# telegram_notify.py
import os, requests
from django.conf import settings

def send_document(filepath, caption=""):
    token = os.environ.get("TELEGRAM_BOT_TOKEN")
    chat_id = os.environ.get("TELEGRAM_BACKUP_CHAT_ID")
    if not token or not chat_id:
        return False, "missing config"
    url = f"https://api.telegram.org/bot{token}/sendDocument"
    with open(filepath, "rb") as f:
        r = requests.post(url, data={"chat_id": chat_id, "caption": caption},
                          files={"document": f}, timeout=60)
    return r.ok, r.text[:200]
```

- في `_maybe_backup`: بعد `create_backup()` → `ok, err = send_document(dest, caption=f"نسخة احتياطية {name}")`؛ اكتب نتيجة الإرسال في `backups/.last_telegram` (timestamp + ok/fail).
- فشل الإرسال **ما يوقفش** إنشاء النسخة المحلية (try/except + log).

**Setup خطوة يدوية منك:** تبعت /start لبوتك من حسابك (أو هنجيب chat_id من getUpdates أول رسالة). أنا هوجهك.

**Verify:** زرار "إنشاء نسخة" من صفحة الإعدادات → الملف يجيلك على تيليجرام فورًا.
